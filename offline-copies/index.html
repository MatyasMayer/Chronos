Offline copies test

Throwaway page for Chronos. It has no server, so results stay on this device until you copy the report at the bottom. Everything you do is logged and the log survives closing the app.

Files in this app's private storage (OPFS):

1. Download, kill and resume

Downloads in 8 MiB Range requests and writes each chunk in place. The video is a real, seekable MP4 of 1.4 GiB (16:40 long).


  1. Kill and resume: start, wait for about 30%, swipe the app away, reopen it, tap Start again. It should continue, not restart. Let it finish and tap Check every byte.
  2. App switch: delete the file, start again, switch to another app for a minute, come back. The log says whether chunks kept arriving.
  3. Screen lock: same, but lock the phone for a minute.
  4. Wake lock: tick Keep screen on and leave the phone alone for two minutes. Does the screen stay on?

2. Video play and seek

Needs the finished test video. Turn on Airplane mode first. Try each route: tap it, press play, run the seek test, then drag the scrubber around yourself and let it play for a few minutes.


3. Storage limit and survival

Survival: leave the finished video in place and don't open this app for 8 days or more. Then open it and tap Check every byte in section 1. Each launch is logged with the time since the last one.

Limit: writes 1 GiB filler files until the cap or until the device refuses. This really uses the space, so pick a cap you can spare, and delete the fillers after.

4. PDF

Builds a 300-page, 180 MiB PDF on this device (needs to be online once, for one picture). Then turn on Airplane mode.



Built-in viewer: these leave the page. Check that the PDF shows, that you can scroll all pages, and that you can get back.

5. PPTX

Fetches a 12-slide test deck into storage (online once). Then, in Airplane mode, try each way to open it. Does Quick Look show the slides?


6. Saving out

Needs the finished test video. Save the full 1.4 GiB file to Files, then check in the Files app that it is there with the right size.

Share sheet: go up in size until it fails or the app reloads. Each tap is logged before the sheet opens, so a crash still shows in the report. In the sheet choose Save to Files.

7. Taking a file back in

Pick the 1.4 GiB video you saved to Files in section 6 (Choose Files). Compare tells you whether the bytes are unchanged; Copy in measures copying it into storage. Then save the video to Photos (Files app, Share, Save Video) and pick it again from Photo Library: are the bytes changed?

8. Windows only: Background Fetch

Starts a browser-run download of many 14 MiB pieces. Start it, close this window (leave the browser itself running), wait, reopen and tap Status. Then repeat and quit the browser fully. Edge: try with "Continue running background extensions and apps" on and off.
